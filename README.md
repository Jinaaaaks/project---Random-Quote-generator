🌸 Random Quote Generator

A simple web app that displays a random inspirational quote each time the user clicks a button. Built using HTML, CSS, and JavaScript.

💡 Features

Displays a random quote at the click of a button.

Minimal and responsive UI.

Smooth color palette for a calming visual effect.

Great for quick daily inspiration or as a beginner JavaScript project.

🧩 Tech Stack

HTML – Structure and layout

CSS – Styling and responsive design

JavaScript – Logic for random quote generation

⚙️ How It Works

An array of motivational quotes is stored inside script.js.

When the user clicks the “New Quote” button, a random quote is selected using JavaScript’s Math.random() function.

The selected quote is displayed dynamically inside the HTML container.

📂 Project Structure
project---Random-Quote-generator/
│
├── index.html      # Main HTML page
├── styles.css      # Styling for layout and design
└── script.js       # JavaScript logic for random quotes

🚀 How to Run

Clone the repository:

git clone https://github.com/Jinaaaaks/project---Random-Quote-generator.git
